      • Power on Trim UI
      • Menu → System Settings → Network
      • Note IP (e.g., 192.168.1.100)

      ./deploy.sh 192.168.1.100 root
   
   3. Test it:
      ssh root@192.168.1.100 /usr/bin/knulli-input-tester

📖 THREE DEPLOYMENT OPTIONS:

   Option A: Automated Script (Easiest)
   ──────────────────────────────────
   ./deploy.sh 192.168.1.100 root
   
   • Builds automatically
   • Transfers binary
   • Installs on device
   • Runs tests
   • Shows device info

   Option B: Using Makefile (Convenient)
   ─────────────────────────────────────
   make deploy IP=192.168.1.100
   
   • Same as deploy.sh but with make
   • Check help: make deploy-help

   Option C: Manual Steps (Flexible)
   ─────────────────────────────────
   make build
   scp build/bin/knulli-input-tester root@192.168.1.100:/tmp/
   ssh root@192.168.1.100 << 'EOF'
   cp /tmp/knulli-input-tester /usr/bin/
   chmod +x /usr/bin/knulli-input-tester
   EOF
   ssh root@192.168.1.100 /usr/bin/knulli-input-tester

═══════════════════════════════════════════════════════════════════════════════════

🎮 CONTROLLER KEYS (Once Running):

   Function + Y       → Cycle button schemes (Knulli/PlayStation/Xbox)
   Function + X       → Toggle event history display
   Function + Select  → Clear all events
   Function + Start   → Export history as JSON/CSV
   Function + Power   → Exit application

🔧 TROUBLESHOOTING:

   SSH Connection Fails?
   • Enable SSH on Knulli: System Settings → Network → SSH → ON
   • Check device is on same WiFi network
   • Verify IP address is correct
   • Test: ping 192.168.1.100

   App Won't Start?
   • Check binary exists: ssh root@<IP> ls -la /usr/bin/knulli-input-tester
   • Verify permissions: ssh root@<IP> chmod +x /usr/bin/knulli-input-tester
   • Check input devices: ssh root@<IP> ls -la /dev/input/

   No Input Events?
   • Device permissions: ssh root@<IP> ls -la /dev/input/event*
   • Check controller connected: ssh root@<IP> cat /dev/input/event0 (press buttons)

✨ OPTIONAL SETUP:

   Run as Background Service:
   ──────────────────────────
   ssh root@<IP> << 'EOF'
   cat > /etc/systemd/system/knulli-input-tester.service << 'SERVICE'
   [Unit]
   Description=Knulli Input Tester
   After=network.target
   
   [Service]
   Type=simple
   User=root
   ExecStart=/usr/bin/knulli-input-tester
   
   [Install]
   WantedBy=multi-user.target
   SERVICE
   
   systemctl daemon-reload
   systemctl enable knulli-input-tester
   systemctl start knulli-input-tester
   EOF
   
   View logs:
   systemctl status knulli-input-tester
   journalctl -u knulli-input-tester -f
